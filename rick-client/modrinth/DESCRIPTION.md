# Rick Client

A small **client-side** Fabric mod for Minecraft 26.2 that gives the game a cherry-blossom look.
**Visual only. No cheats, no gameplay changes.**

## Features
- **Sakura title screen**: a dusk gradient in purple and pink with falling cherry petals and the Rick Client logo.
- **Sakura Swing**: a custom, smooth sweeping hand animation when you swing or attack. It changes only how your hand looks, not reach, damage or cooldown. You can switch it on and off in the title screen.

## Compatibility
- Minecraft 26.2, Fabric Loader 0.19+, Java 25
- Client-side only. Install it on your own game, never on a server.
- Fabric API is not required.

## Fairness
Rick Client does not give any advantage in PvP or anywhere else. It only changes visuals on your own screen.
